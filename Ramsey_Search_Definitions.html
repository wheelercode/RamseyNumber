Ramsey Search Definitions and Research Glossary

This document collects the mathematical, graph-theoretic, search, and machine-learning terminology used throughout the RamseyNumber project and our R(5,5) research. It is intended as a human reference: formal enough to remove ambiguity, but written so that a term can be understood without remembering the conversation in which it was introduced.

The central problem is to color every edge of the complete graph on 43 vertices either red or blue while minimizing the number of monochromatic copies of K5K_5.

1. Core Ramsey and Graph-Theory Definitions

Graph

A graph consists of a set of vertices and a set of edges joining pairs of vertices.

In this project the host graph is complete: every distinct pair of vertices has an edge.

Vertex

A vertex is a node of a graph. In the party interpretation, a vertex represents a person.

For K43K_{43} there are 43 vertices, conventionally indexed 0,1,…,420,1,\ldots,42 in the code.

Edge

An edge joins two distinct vertices. In the party interpretation, its color describes the relationship between those two people.

For K43K_{43}:

(432)=903 \binom{43}{2}=903

so a complete coloring contains 903 independently colored edges.

Simple or ordinary graph

A simple graph (what we earlier called an ordinary graph) has no self-loops and no duplicate edges between the same pair of vertices.

When a red/blue coloring is converted into an ordinary graph, we can keep one color as the graph's edges and treat the other color as non-edges. A blue clique then becomes an ordinary clique, while a red clique becomes an independent set, or vice versa.

Complete graph, KnK_n

KnK_n is the complete graph on nn vertices: every pair of distinct vertices is joined by an edge.

Examples:

  • K43K_{43} has 43 vertices and 903 edges.
  • K5K_5 has 5 vertices and 10 edges.

Subgraph

A subgraph is a graph formed from some subset of a graph's vertices and/or edges.

Every five-vertex subset of K43K_{43} induces a K5K_5 because the host graph is complete.

Clique

A clique is a set of vertices in which every pair is connected by an edge.

A clique of size kk is a copy of KkK_k.

Independent set

An independent set is a set of vertices containing no edges in an ordinary graph representation.

If blue edges are retained and red edges are treated as absent, an all-red K5K_5 in the two-color representation appears as a five-vertex independent set in the blue-only graph.

Connected graph

A graph is connected if every vertex can be reached from every other vertex by following edges.

K43K_{43} is automatically connected. Connectivity is not a restriction on our red/blue coloring because every host edge exists; only its color changes.

Isolated vertex

An isolated vertex in an ordinary graph has degree zero. This notion is representation-dependent: a vertex may have degree zero in the blue-only graph while still having 42 red relationships in the two-color representation.

Degree, d(v)d(v)

The degree d(v)d(v) of a vertex is the number of graph edges incident to it.

In K43K_{43} every vertex has total degree 42.

For a red/blue coloring we can split this into:

dR(v)+dB(v)=42. d_R(v)+d_B(v)=42.

Vertex color imbalance

A vertex color imbalance measures the difference between the numbers of red and blue edges incident to a vertex. One natural signed form is

dB(v)−dR(v). d_B(v)-d_R(v).

A value of zero means a 21/21 split. Our experiments showed that low Ramsey score does not require every vertex to be perfectly balanced.

Edge coloring

An edge coloring assigns a color to every edge of the host graph.

Our search uses two colors:

  • 0 = red
  • 1 = blue

Monochromatic

A subgraph is monochromatic if all of its relevant edges have the same color.

A monochromatic K5K_5 therefore has either 10 red edges or 10 blue edges.

Violation

A violation is a monochromatic forbidden clique. For the R(5,5) search, a violation is an all-red or all-blue K5K_5.

Ramsey number, R(a,b)R(a,b)

R(a,b)R(a,b) is the smallest integer nn such that every red/blue edge coloring of KnK_n contains either:

  • a red KaK_a, or
  • a blue KbK_b.

The color names can be swapped without changing the mathematics.

R(5,5)R(5,5)

R(5,5)R(5,5) is the smallest nn for which every two-coloring of KnK_n necessarily contains a monochromatic K5K_5.

Our computational work studies colorings of K43K_{43} that have as few monochromatic K5K_5s as possible.

Party interpretation

The party problem interprets vertices as people and edge colors as relationships, for example:

  • blue = know each other
  • red = strangers

A monochromatic clique is therefore a group whose pairwise relationships are all of the same type.

Binomial coefficient, (nk)\binom{n}{k}

(nk)\binom{n}{k}, read “nn choose kk,” is the number of ways to choose an unordered kk-element subset from nn elements:

(nk)=n!k!(n−k)!. \binom{n}{k}=\frac{n!}{k!(n-k)!}.

Important values in this project are:

(432)=903 \binom{43}{2}=903

edges and

(435)=962,598 \binom{43}{5}=962,598

five-vertex subsets, hence 962,598 copies of K5K_5.

K5s containing one edge

Once one edge has fixed two of the five vertices, the other three vertices can be chosen from the remaining 41:

(413)=10,660. \binom{41}{3}=10,660.

Therefore every edge of K43K_{43} participates in exactly 10,660 different K5K_5s.

2. Coloring and Data Representations

903-bit coloring

A complete K43 red/blue coloring can be represented by one bit per edge. Since K43 has 903 edges, the complete state is a 903-bit coloring.

Symmetric adjacency/color matrix

The same coloring may be displayed as a symmetric 43×4343\times43 matrix. Entry (i,j)(i,j) gives the color of edge (i,j)(i,j). The diagonal does not represent edges and is unused.

The 903-bit representation is generally more compact and convenient for search.

Edge table

The edge table maps each edge index to its two endpoints:

edge_index -> (vertex_i, vertex_j)

For K43 it has shape (903, 2).

Edge-index lookup

An edge-index lookup performs the inverse mapping:

(vertex_i, vertex_j) -> edge_index

It is useful while constructing incidence tables but is not itself the coloring.

Clique table / K5 edge table

The K5 edge table stores the ten host-edge indexes belonging to each five-vertex subset.

For K43/K5 its shape is:

(962598, 10)

Edge-to-K5 incidence table

The edge-to-K5 table lists every K5 containing each host edge. For K43 its shape is:

(903, 10660)

This table is crucial for fast incremental updates after an edge flip.

Coloring state

A state is one complete current coloring together with the derived information maintained for search, such as the K5 histogram, exact score, and cached action profiles.

State version

A state version is a mutation counter. Analyses associated with an earlier version are stale after the coloring changes.

Coloring hash / state key

A coloring hash or exact state key is a compact identifier for a coloring, typically derived from its 903 bits. It lets search memory recognize a coloring it has already visited without comparing higher-level structures manually.

Hashing does not improve a coloring; it makes state lookup and cycle detection efficient.

3. K5 Histogram, Score, and Violations

Blue-edge count of a K5

Every K5 has 10 edges. Its blue-edge count is therefore an integer from 0 through 10.

If it has bb blue edges, it has 10−b10-b red edges.

K5 histogram

The K5 histogram HH has 11 bins:

H0,H1,…,H10. H_0,H_1,\ldots,H_{10}.

HbH_b is the number of K5s containing exactly bb blue edges.

Thus:

  • H0H_0 = all-red K5s
  • H10H_{10} = all-blue K5s
  • central bins describe increasingly balanced K5s

and

∑b=010Hb=962,598. \sum_{b=0}^{10}H_b=962,598.

Ramsey score, S(G)S(G)

The Ramsey score of a coloring is the number of monochromatic K5s:

S(G)=H0+H10. \boxed{S(G)=H_0+H_{10}}.

Lower is better. A score-zero K43 coloring would contain no monochromatic K5s.

Scalar score

A scalar score reduces the quality of an entire coloring to one number. Our central warning is that a scalar destroys structural information: two graphs with the same Ramsey score can have very different internal constraint structures and search behavior.

Score distance

The score distance is the naive idea that a graph with score 100 is “closer” to a solution than a graph with score 500 simply because 100 is numerically closer to zero.

Our experiments show that score is not necessarily a reliable measure of search difficulty.

Search distance

Search distance is the still-unknown difficulty of actually reaching a zero-score coloring from a state. Unlike Ramsey score, it depends on the structure of the surrounding coloring space and the actions available to the search algorithm.

4. Completion Deficits and Danger

Red completion deficit

For a K5 containing bb blue edges, its red completion deficit is bb: that many edges would have to become red to make the K5 all red.

Blue completion deficit

For the same K5, its blue completion deficit is 10−b10-b: that many edges would have to become blue to make it all blue.

The two colors are deliberately kept separate because they describe different potential failure modes.

Deficit 0

A deficit-0 K5 is already monochromatic in the relevant color and is therefore an actual violation.

Deficit 1

A deficit-1 K5 is one edge recoloring away from becoming monochromatic. It is a near-violation.

Examples include 9-red/1-blue when considering all-red completion and 9-blue/1-red when considering all-blue completion.

Deficit 2

A deficit-2 K5 requires two edge recolorings to become monochromatic in the relevant color.

Deficit 3 and higher

Deficit 3, and analogously higher deficits, count how many edge changes separate the K5 from a monochromatic state in a particular color.

They provide graded information discarded by the binary violation/not-violation score.

Danger

Danger is a heuristic notion of how close a K5 is to becoming monochromatic. Low completion deficit means greater danger.

Danger objective / danger energy

A danger objective assigns graded weights to K5 histogram bins so that near-violations matter before they become actual violations. It provides a smoother objective than the all-or-nothing Ramsey score.

Danger decay

Danger decay controls how quickly the weight given to near-violations falls as their completion deficit grows.

K5 safety level, L(K)L(K)

The K5 safety level is a color-symmetric measure of how far a K5 is from its nearest monochromatic state. If the K5 contains bb blue edges and 10−b10-b red edges, define

L(K)=min(b,10−b). \boxed{L(K)=\min(b,10-b)}.

Therefore:

Red/blue composition L(K)L(K) Interpretation
10/0 or 0/10 0 monochromatic violation
9/1 or 1/9 1 extremely dangerous
8/2 or 2/8 2 dangerous
7/3 or 3/7 3 moderately safe
6/4 or 4/6 4 quite safe
5/5 5 maximally balanced

This is closely related to completion deficit, but deliberately collapses the red and blue directions into one color-symmetric safety coordinate.

Balanced K5

A balanced K5 is a K5 with five red and five blue edges. It has the maximum safety level L(K)=5L(K)=5.

The word balanced is preferable to neutral K5, because a neutral action already has the separate meaning of an action whose immediate Ramsey reward is zero.

Structural safety

Structural safety refers to the distribution of K5s away from the monochromatic boundary, rather than merely the number that are currently monochromatic.

Two colorings with the same Ramsey score can therefore have different structural safety: one may contain many 9/1 near-violations while the other places more of its K5s around 6/4 and 5/5.

Safety change of an edge, ΔL(e)\Delta L(e)

For a proposed edge flip ee, its unweighted safety change can be defined over the 10,660 K5s containing that edge:

ΔL(e)=∑K∋e[L(Kafter)−L(Kbefore)]. \boxed{\Delta L(e)=\sum_{K\ni e}\left[L(K_{\mathrm{after}})-L(K_{\mathrm{before}})\right]}.

A positive value means the flip moves its affected K5 neighborhood collectively farther from monochromaticity; a negative value means it moves that neighborhood toward danger.

Weighted structural-safety objective, Q(G)Q(G)

A weighted structural-safety objective assigns a nonlinear value q(L)q(L) to each safety level and sums it over every K5:

Q(G)=∑Kq(L(K)). Q(G)=\sum_K q(L(K)).

The weights can make movement away from the dangerous 9/1 boundary more important than movement from 6/4 to 5/5. The particular weights are an experimental policy choice, not a Ramsey-theoretic identity.

For an action, ΔQ\Delta Q measures its change in this structural-safety objective. This gives a richer action description such as (ΔS,ΔQ)(\Delta S,\Delta Q) instead of ranking an edge solely by immediate Ramsey-score change.

5. Actions and Exact Consequences

Action

An action is one permitted transformation of a coloring.

The simplest action in our search is a single edge flip.

Single-edge flip

A single-edge flip changes exactly one host edge:

red -> blue

or

blue -> red

There are 903 possible single-edge actions in a K43 coloring before memory restrictions are applied.

Two-edge action

A two-edge action changes two edges as one search move. It explores a larger neighborhood than single-edge greedy search and can potentially cross barriers invisible to a one-edge neighborhood.

K5 macro action

A K5 macro action recolors multiple edges belonging to one chosen K5 as a single action. It allows the search to manipulate K5-level structure rather than building every transformation from one-edge moves.

K5 pattern

A K5 pattern is one red/blue assignment of the ten edges of a K5. There are

210=1024 2^{10}=1024

possible patterns, of which two are monochromatic.

Vertex-balance action

A vertex-balance action attempts to change edge colors in a way that alters red/blue degree imbalance at vertices. Experiments showed that our low-score archive graphs were already remarkably degree-balanced, so simple vertex balance did not provide an escape mechanism.

Action analysis

An action analysis computes the consequences of candidate actions without applying them to the real search state.

For single-edge actions this includes exact resulting score changes and K5-profile changes for all 903 edges.

Counterfactual

A counterfactual asks what the state or a metric would become if a candidate action were taken, without committing that action to the real search state.

Action landscape

The action landscape is the complete collection of candidate actions and their predicted consequences at one state.

It is more informative than merely asking for the single action with maximum reward.

Histogram delta

A histogram delta is the exact change to every K5 histogram bin caused by an action:

ΔH=Hafter−Hbefore. \Delta H=H_{\text{after}}-H_{\text{before}}.

Exact immediate reward, r(e)r(e)

For an edge flip ee, the exact immediate reward is

r(e)=Sbefore−Safter. \boxed{r(e)=S_{\text{before}}-S_{\text{after}}}.

Therefore:

  • r(e)>0r(e)>0: the score improves
  • r(e)=0r(e)=0: the score is unchanged
  • r(e)<0r(e)<0: the score worsens

Improving action

An improving action has positive exact reward.

Neutral action

A neutral action has zero exact reward. It may still dramatically reorganize which constraints are active.

Neutral does not mean structurally irrelevant.

Worsening or uphill action

A worsening or uphill action has negative exact reward and temporarily creates a higher Ramsey score.

Such moves may be valuable if they reorganize constraints or escape a rigid basin.

Score-increasing move

A score-increasing move is another name for an uphill move: Safter>SbeforeS_{\text{after}}>S_{\text{before}}.

Created and destroyed violations

For an action, destroyed violations are monochromatic K5s eliminated by the move, while created violations are new monochromatic K5s introduced by it.

The scalar reward keeps only the difference. For example, destroying 7 and creating 7 has reward zero, as does destroying 0 and creating 0, despite radically different structural effects.

6. Edge Role Profiles: N1 Through N10

Same-color multiplicity, kk

Consider an edge ee inside one particular K5. Let kk be the number of the K5's ten edges having the same color as ee.

kk ranges from 1 through 10.

Edge role profile, (N1,…,N10)(N_1,\ldots,N_{10})

Every K43 edge belongs to 10,660 K5s. For an edge ee, define

Nk(e) N_k(e)

as the number of incident K5s in which exactly kk of the ten K5 edges have the same color as ee.

The full discrete role profile is

(N1,N2,…,N10). \boxed{(N_1,N_2,\ldots,N_{10})}.

and

∑k=110Nk(e)=10,660. \sum_{k=1}^{10}N_k(e)=10,660.

N1N_1: unique-blocker load

N1(e)N_1(e) counts K5s in which ee is the only edge of its current color.

Example: in a 9-blue/1-red K5, the lone red edge is the unique blocker preventing an all-blue violation.

Flipping that edge would create a monochromatic K5. Thus N1N_1 measures an exact form of blocker liability.

N10N_{10}: violation participation

N10(e)N_{10}(e) counts monochromatic K5s containing edge ee.

Flipping ee destroys all of those same-color violations.

Greedy reward identity

For a single edge flip:

r(e)=N10(e)−N1(e). \boxed{r(e)=N_{10}(e)-N_1(e)}.

N10N_{10} counts violations destroyed; N1N_1 counts opposite-color violations created.

This identity explains exactly what the ordinary exact greedy algorithm sees and what it discards: N2N_2 through N9N_9 do not affect immediate score reward.

Blocker

A blocker is an edge whose current color prevents a nearly monochromatic K5 from becoming an actual violation.

A unique blocker is the single minority-color edge of a 9/1 K5.

Blocker liability

The blocker liability of an edge is the number or structure of near-violations that depend critically on its current color. N1N_1 is the simplest exact form of this measurement.

Violation load

An edge's violation load is the number of current monochromatic K5s containing it. For single edges this is N10N_{10}.

The analogous vertex violation load counts monochromatic K5s containing a particular vertex.

7. Flipability

Local discrete flipability

For an edge ee inside one K5, with kk same-color edges in that K5, we defined the local discrete flipability as

flocal=k−1. \boxed{f_{\text{local}}=k-1}.

Examples:

  • unique minority edge in a 9/1 K5: k=1k=1, flipability 00
  • an edge with four same-color companions: k=5k=5, flipability 44
  • edge in a monochromatic K5: k=10k=10, flipability 99

Global edge flipability

The original global scalar flipability was

Fflip(e)=∑k=110(k−1)Nk(e). \boxed{F_{\text{flip}}(e)=\sum_{k=1}^{10}(k-1)N_k(e)}.

Important limitation of scalar flipability

We discovered that this scalar collapses mostly to ordinary color-degree information. If ee has color cc, let McM_c be the total number of color-cc edges and let ses_e be the number of other color-cc edges sharing an endpoint with ee. Then

Fflip(e)=741se+39(Mc−1). F_{\text{flip}}(e)=741s_e+39(M_c-1).

Therefore the full N1,…,N10N_1,\ldots,N_{10} vector retains substantially more K5-level information than the scalar flipability sum.

Flipability versus flexibility

Flipability and flexibility are different concepts in this project.

  • Flipability describes an edge's accumulated local same-color roles in K5s.
  • Flexibility describes how much of the action space can be used without exceeding a specified score-damage budget.

8. Flexibility

Damage budget, bb

A damage budget b≥0b\ge0 is the maximum temporary Ramsey-score increase we are willing to tolerate for one action.

Flexibility, F(b)F(b)

For one coloring, let r(e)r(e) be the exact reward of each of its 903 possible edge flips. We define

F(b)=#{e:r(e)≥−b}903 \boxed{ F(b)=\frac{\#\{e:r(e)\ge-b\}}{903} }

when all 903 structural actions are being considered.

F(b)F(b) is the fraction of actions that improve the score, leave it unchanged, or worsen it by no more than bb.

F(0)F(0)

F(0)=#{e:r(e)≥0}903. F(0)=\frac{\#\{e:r(e)\ge0\}}{903}.

It is the fraction of single-edge flips that do not worsen the Ramsey score.

It includes both improving and neutral actions.

F(1)F(1)

F(1)F(1) is the fraction of edge flips that worsen the score by at most one violation. It includes everything counted by F(0)F(0) plus moves having reward −1-1.

F(2)F(2), F(3)F(3), F(4)F(4), F(5)F(5), ...

The definition continues identically:

  • F(2)F(2) allows at most +2 score damage
  • F(3)F(3) allows at most +3
  • F(4)F(4) allows at most +4
  • F(5)F(5) allows at most +5
  • F(10)F(10) allows at most +10
  • and so on

Since larger damage budgets include all smaller-budget actions,

F(0)≤F(1)≤F(2)≤⋯. F(0)\le F(1)\le F(2)\le\cdots.

Flexibility curve

The flexibility curve is the vector or function

(F(0),F(1),F(2),F(3),…). \boxed{(F(0),F(1),F(2),F(3),\ldots)}.

We deliberately retain the curve instead of immediately reducing flexibility to another scalar.

Flexibility reserve

A flexibility reserve is the current amount of maneuverability available to search. For example, an experiment may monitor F(5)F(5) and attempt to keep it above some threshold.

Flexibility as search capital

Calling flexibility search capital emphasizes that it is a resource that can be spent. A search does not necessarily want maximum flexibility forever; it wants to avoid wasting flexibility for poor score gains.

Flexibility as opportunity

Our matched-score release experiment suggested that flexibility is better interpreted as opportunity than as progress. A high-flexibility state gives the algorithm more inexpensive choices, but a greedy policy can immediately squander those choices.

Counterfactual flexibility

The counterfactual flexibility of action aa is the flexibility curve of the state that would result if aa were taken:

Fb(S∣a)=Fb(S′). F_b(S\mid a)=F_b(S').

Flexibility delta, ΔF\Delta F

For one action:

ΔF(b)=Fafter(b)−Fbefore(b). \Delta F(b)=F_{\text{after}}(b)-F_{\text{before}}(b).

Positive ΔF\Delta F means the move creates more maneuverability at that damage budget.

Local flexibility

Local flexibility is the one-step flexibility described by F(b)F(b): how many acceptable moves are available right now.

Multi-step flexibility

Multi-step flexibility concerns how many distinct states or useful trajectories can be reached over several actions while remaining within some score budget.

It is more expensive to calculate but describes basin geometry more directly than one-step F(b)F(b).

Reachable volume

The reachable volume is the number or diversity of states reachable from a coloring under specified action, depth, and score constraints. It is one possible higher-order measure of flexibility.

9. Rigidity, Cages, Basins, and Repairability

Rigidity

Rigidity is our informal name for a state in which many edge colors have become structurally load-bearing, so changing them tends to create new violations or near-violations.

Rigidity is not currently one single formal scalar. N1N_1 distributions, flexibility curves, repair costs, and action landscapes are all ways of measuring aspects of it.

Cage

The cage is our descriptive term for the highly constrained structure built by repeated greedy score optimization. Greedy removes easy violations while progressively making remaining edges dangerous to change.

Basin

A basin is a region of coloring space into which a search descends and from which improving moves become difficult or unavailable.

Local minimum

A single-edge local minimum is a state in which no permitted single-edge flip improves the score.

This is not necessarily globally optimal. It only describes the selected neighborhood/action space.

Plateau

A plateau is a region in which many reachable states have the same objective value, so neutral moves can traverse the region without immediate score progress.

Escape barrier

The escape barrier of a state is the smallest temporary score increase required along any path that eventually reaches a state with a better score.

Conceptually:

B(S)=minpaths to a better state(maxtSt−S0). B(S)=\min_{\text{paths to a better state}}\left(\max_t S_t-S_0\right).

If B(S)=0B(S)=0, a neutral/non-worsening route to improvement exists. If B(S)>0B(S)>0, some temporary worsening is unavoidable along every escape path.

Repair handle

A repair handle is an edge of a current violation that can be flipped at relatively low cost to surrounding constraints.

Repair cost of a violation, C(K)C(K)

For a monochromatic K5 KK, we proposed

C(K)=mine∈KN1(e). \boxed{C(K)=\min_{e\in K}N_1(e)}.

This measures the minimum number of opposite-color violations that would be created by flipping one edge of that K5, before accounting for other same-color violations that the same flip may also destroy.

If C(K)=0C(K)=0, the violation currently has a clean repair handle: at least one of its edges can be flipped without immediately creating an opposite-color monochromatic K5.

Repair landscape

The repair landscape of a violation is the collection

{(N10(e),N1(e)):e∈K} \{(N_{10}(e),N_1(e)):e\in K\}

over its ten edges. It shows destruction leverage and creation liability for every local repair choice.

Structural disorder / frustration

Structural disorder or frustration describes the situation in which many overlapping constraints demand mutually awkward edge assignments. The terms are descriptive rather than a single formal project metric.

10. Greedy and Flexibility-Aware Search

Greedy search

A greedy search chooses the action with the best immediate objective value at every step without explicitly optimizing long-term consequences.

Exact-score greedy

Our exact single-edge greedy policy chooses an available edge maximizing

r(e)=N10(e)−N1(e). r(e)=N_{10}(e)-N_1(e).

It therefore maximizes immediate net violation reduction, not simply raw violation participation.

Score-first greedy

Score-first greedy is our name for treating immediate Ramsey score reduction as the primary action-selection rule.

Our experiments show that it rapidly reduces score but also strongly reduces flexibility.

Greedy as a flexibility sink

Calling greedy a flexibility sink summarizes the experimental observation that even when given a higher-flexibility state at approximately the same score, ordinary greedy rapidly consumes the flexibility advantage and drives states toward a similar rigid score/flexibility regime.

Flexibility-aware policy

A flexibility-aware policy considers the future action landscape in addition to immediate Ramsey score.

Our first adaptive implementation switched from score-first behavior to flexibility preservation when a monitored F(b)F(b) fell below a configured floor.

Fixed flexibility floor

A flexibility floor is a threshold such as

F(5)≥55%. F(5)\ge55\%.

The controller attempts to restore flexibility after dropping below that level. This produced thermostat-like oscillation and was useful experimentally, but it is not assumed to be the final objective.

Flexibility-first descent

Flexibility-first descent is the proposed strategy of modifying greedy behavior from the beginning:

  1. require score progress whenever acceptable improving moves exist;
  2. among those moves, prefer the action that preserves the strongest future flexibility;
  3. when no improving move is available, gradually admit neutral and then increasingly uphill actions.

This treats score improvement as a constraint and future maneuverability as a major selection criterion.

Score/flexibility tradeoff

Each action can be viewed as producing at least two consequences:

(ΔS,ΔF). (\Delta S,\Delta F).

An action may improve both, worsen both, or trade one for the other.

Flexibility efficiency

Flexibility efficiency informally means obtaining useful Ramsey score progress while consuming as little flexibility as possible.

We have intentionally not committed to one scalar ratio because dividing these quantities could again destroy useful multidimensional information.

11. Pareto Terminology

Objective vector

An objective vector records several consequences of an action rather than compressing them into one scalar. For example:

(r(e),F0(S′),F1(S′),F2(S′),F5(S′),…). (r(e),F_0(S'),F_1(S'),F_2(S'),F_5(S'),\ldots).

Pareto dominance

Suppose actions AA and BB are judged on several quantities that we want to maximize. AA Pareto-dominates BB if:

  1. AA is at least as good as BB in every objective, and
  2. AA is strictly better in at least one objective.

There is then no reason to choose BB if all listed objectives genuinely matter and no hidden consideration distinguishes them.

Dominated action

A dominated action is an action for which another candidate is at least as good in every considered objective and better in at least one.

Pareto frontier

The Pareto frontier is the set of nondominated actions.

These actions represent genuine tradeoffs. For example, one might give greater score improvement while another preserves more flexibility, with neither being unambiguously better on both axes.

Nondominated action

A nondominated action is a member of the Pareto frontier: no candidate simultaneously beats it on all considered objectives.

12. Search Memory and Exploration

Search memory

Search memory is information about previous actions or states that influences which actions are currently permitted or preferred.

Tabu search

Tabu search temporarily forbids recently used actions or recently visited states so that local search does not immediately undo itself or fall into short cycles.

Tabu edge tenure

The edge tenure is the number of subsequent steps for which a recently flipped edge remains tabu.

Visited-state window

The visited-state window is the bounded number of recent exact colorings remembered so the search can reject or discourage revisiting them.

Aspiration

Aspiration permits an otherwise tabu action when that action is sufficiently valuable, such as when it creates a new best exact score.

Cycle

A cycle occurs when search returns to a state it has already visited and may begin repeating an action sequence.

Random restart

A random restart abandons one search trajectory and begins from a new randomly generated state.

Seed coloring

A seed coloring is the starting coloring supplied to a search attempt.

Seeds may be random, archive-derived, cyclic, constructive, manually specified, or generated by another algorithm.

Trajectory

A trajectory is the ordered sequence of states, actions, scores, or measurements produced by a search run.

13. Construction and Archive Terminology

Construction

A construction is an algorithm that creates a starting coloring rather than improving an already active coloring through ordinary search steps.

Random construction

A random construction independently assigns red or blue to each host edge, normally with equal probability.

A random K43 coloring has roughly 1,800–1,900 monochromatic K5s on average in our experiments.

Cyclic / circulant construction

A cyclic or circulant construction places vertices on a modular circle and colors an edge according to the modular/circular distance between its endpoints.

This imposes strong symmetry and reduces the number of independent coloring decisions.

Circular distance

For vertices labeled modulo nn, the circular distance between ii and jj is

min(|i−j|,n−|i−j|). \min(|i-j|,n-|i-j|).

A cyclic coloring assigns colors to distance classes rather than to each edge independently.

Quadratic-residue coloring

A quadratic-residue coloring colors differences between modular vertex labels according to whether the difference belongs to a selected residue class, such as the nonzero squares modulo a prime. Such highly symmetric constructions are classical tools in Ramsey lower-bound constructions.

Symmetry reduction

Symmetry reduction recognizes that vertex renamings or color swaps can describe colorings that are structurally equivalent. Avoiding redundant equivalent states can reduce the effective search space.

Vertex renaming / graph isomorphism

A vertex renaming permutes vertex labels without changing the abstract colored graph. Two colorings related only by such a permutation are isomorphic.

Color symmetry

Because R(5,5) treats red and blue identically, swapping every red edge with blue and every blue edge with red produces an equivalent score structure.

Archive

The archive is the persistent database of useful discovered colorings. It lets later experiments reuse structured states instead of starting from random graphs every time.

Archive record

An archive record stores a coloring together with identifying and experimental metadata such as score, run name, or iteration.

Population

A population is a collection of candidate colorings considered together, for example as seeds for evolutionary, batch, or curriculum search.

Ancestor / descendant coloring

A coloring is an ancestor of another if the latter was produced by continuing search or mutation from the former. Archive populations can contain many related descendants rather than statistically independent discoveries.

Diversity

Diversity measures how structurally different candidate colorings are. A large archive can have low true diversity if most entries are minor descendants of the same few ancestors.

14. Experimental Metrics and Comparisons

Matched-score comparison

A matched-score comparison compares two colorings having the same or nearly the same Ramsey score but different values of another structural metric.

This is essential for determining whether a proposed metric contains information beyond score itself.

Matched-score flexibility release

Our matched-score flexibility release experiment constructed approximately score-550 graphs with different F(5)F(5) values, reset search memory, and then ran identical greedy search from each.

It tests whether flexibility predicts future search behavior beyond current score.

Baseline

A baseline is the control algorithm against which a new strategy is compared. Exact greedy single-edge search has served as a major baseline in this project.

Benchmark

A benchmark is a fixed experimental procedure, set of seeds, or evaluation population used to compare algorithms under controlled conditions.

Control surface

A control surface is one major aspect of the search system that we can change independently to influence results.

15. Objectives, Policies, and Search Architecture

Objective

An objective defines what the search regards as desirable. The exact monochromatic-K5 count is one objective; a danger-weighted measure is another.

An objective need not be identical to the final theorem condition.

Scoring function

A scoring function calculates a numerical description of state quality. The exact Ramsey score is

H0+H10. H_0+H_{10}.

Reward

A reward is feedback associated with an action or transition. In exact edge search it is the score reduction. In reinforcement learning it is the numerical feedback used to train behavior.

Policy

A policy is a rule for choosing an action given a state.

In reinforcement-learning notation:

π(a∣s) \pi(a\mid s)

describes the probability or preference of taking action aa when the system is in state ss.

A greedy policy, random policy, tabu-aware policy, and neural policy are all different policies.

Search

Search is the process that repeatedly applies policies/actions to explore coloring space.

Environment

The environment owns the active search state and applies selected actions. It also handles transition validation, termination, memory restrictions, and other search mechanics. The policy chooses; the environment executes.

Search episode / run

A search episode or run is one complete trajectory beginning from a seed and ending when a stopping condition is reached.

Iteration

An iteration is one repeated unit of an experiment or training process. In PPO training, for example, an iteration may collect a rollout and then update the network.

16. Neural-Network and Reinforcement-Learning Definitions

Neural network

A neural network is a parameterized function composed of layers whose weights are learned from data or feedback.

In this project the network was used to estimate action preferences and state value from graph-derived inputs.

Parameter / weight

A parameter or weight is a learned numerical value inside a neural network. Training updates parameters; ordinary inference uses their current values without changing them.

Feature

A feature is an input quantity or learned internal signal that carries information useful for prediction or action selection.

Encoding

An encoding transforms raw problem state into explicit numerical inputs suitable for an algorithm or model.

Encoding is what we choose to show the model.

Embedding

An embedding is a learned vector representation in which objects or structures are mapped into a continuous feature space.

Embedding is generally learned internally rather than being a raw hand-designed state description.

Hidden representation

A hidden representation is the intermediate vector/tensor produced inside a neural network after transforming its inputs.

Message-passing layer

A message-passing layer updates a graph element's representation using information from related graph elements. Repeated layers allow information to propagate through graph structure.

Attention

Attention is a learned mechanism that dynamically weights the relevance of different inputs when constructing a representation. It is related in spirit to message passing because both aggregate information, but attention learns content-dependent weights rather than necessarily using a fixed neighborhood aggregation rule.

Head

A head is an output branch of a shared neural representation specialized for a particular prediction.

Policy head

The policy head produces action logits/preferences. In the K43 edge policy it ultimately assigns a preference to candidate edge flips.

Value head

The value head estimates the expected future cumulative reward from the current state.

Logit

A logit is an unnormalized action score produced by a neural network before conversion into probabilities.

Categorical policy distribution

A categorical distribution converts action logits into probabilities over discrete actions and allows an action to be sampled.

Reinforcement learning (RL)

Reinforcement learning trains an agent by interacting with an environment and using rewards to increase the probability of useful behavior.

State, sts_t

sts_t denotes the environment state at time step tt.

Action, ata_t

ata_t denotes the action chosen at time step tt.

π(at∣st)\pi(a_t\mid s_t)

π(at∣st)\pi(a_t\mid s_t) is the policy's probability of choosing action ata_t conditioned on being in state sts_t.

The vertical bar means “given” or “conditioned on.”

Rollout

A rollout is a recorded sequence of states, actions, rewards, action probabilities, and value estimates generated by running the current policy through the environment.

Return

The return is the discounted cumulative future reward used as a training target.

Discount factor, γ\gamma

The discount factor controls the relative importance of future rewards:

0≤γ≤1. 0\le\gamma\le1.

Values near one make long-term rewards matter nearly as much as immediate ones.

Value, V(s)V(s)

The value of state ss is the model's estimate of expected future cumulative reward from that state under the current policy.

It is not the Ramsey score.

Advantage, AtA_t

The advantage estimates how much better or worse action ata_t was than the policy/value model expected from state sts_t.

Positive advantage means the sampled action performed better than the baseline expectation; negative advantage means worse.

GAE / generalized advantage estimation

Generalized Advantage Estimation (GAE) combines temporal-difference errors across time to produce lower-variance advantage estimates.

GAE lambda, λ\lambda

The GAE lambda parameter controls the bias/variance tradeoff in how far advantage information is propagated through a rollout.

PPO

Proximal Policy Optimization (PPO) is a reinforcement-learning algorithm that updates the policy using collected rollouts while limiting how far the new policy moves from the behavior that generated those rollouts.

PPO probability ratio

PPO uses

ρt=πnew(at∣st)πold(at∣st). \rho_t=\frac{\pi_{\text{new}}(a_t\mid s_t)}{\pi_{\text{old}}(a_t\mid s_t)}.

The ratio measures how much the new policy has changed the probability of the sampled action.

Clip ratio

The PPO clip ratio limits the useful range of the probability ratio, preventing one training update from receiving unlimited benefit by making an action dramatically more or less probable.

Clipped fraction

The clipped fraction is the fraction of training samples whose probability ratios moved outside PPO's clipping interval.

Large clipped fraction means many proposed policy changes are large enough for clipping to become active.

Policy loss

The policy loss is the optimization loss derived from PPO's clipped policy objective. Its sign by itself is not a score saying whether the current Ramsey policy is “good” or “bad.” It is primarily meaningful as part of the optimization/update process.

Value loss

The value loss measures disagreement between the value head's predictions and the return targets, commonly using squared error.

Entropy

Policy entropy measures how spread out the action probability distribution is.

High entropy means the policy assigns probability broadly across actions. Low entropy means it is concentrated on fewer actions.

For 903 equally probable actions the maximum entropy is approximately

ln(903)≈6.806. \ln(903)\approx6.806.

Entropy bonus / entropy weight

An entropy bonus rewards exploration by discouraging the policy from collapsing too quickly onto a small number of actions. The entropy weight controls its contribution to the training loss.

KL divergence

Kullback-Leibler (KL) divergence measures how different one probability distribution is from another.

In PPO it is used diagnostically to estimate how much the updated policy has moved from the rollout policy.

Approximate KL

Approximate KL is a computational estimate of policy change, often formed from differences between old and new action log-probabilities over rollout samples.

Log probability

The log probability of an action is the natural logarithm of the policy probability assigned to that action. Log probabilities are numerically convenient for probability ratios and likelihood optimization.

Learning rate

The learning rate controls the size of neural-network parameter updates made by the optimizer.

Gradient

A gradient gives the direction and sensitivity of loss with respect to model parameters.

Gradient clipping

Gradient clipping limits unusually large gradient magnitudes to reduce unstable parameter updates.

Minibatch

A minibatch is a subset of collected training samples processed together during one optimizer update.

Update epoch

An update epoch is one pass through a collected rollout dataset during training. PPO commonly makes several passes over the same rollout.

Checkpoint

A checkpoint is a saved training state, typically including neural-network weights, optimizer state, configuration, iteration number, and sometimes random-number-generator state.

It allows training or evaluation to resume from a prior point.

Inference

Inference means using a trained network to produce predictions/actions without updating its parameters.

Training

Training means updating model parameters using an optimization algorithm and training data/rewards.

Curriculum

A curriculum controls the distribution and difficulty of states used during training. Our phases used progressively stronger archived colorings so later models could learn from lower-score regions rather than only random graphs.

17. Search-Space and Learning Concepts

Search space

The search space is the set of all colorings or states the algorithm could potentially consider.

For K43 with two colors and 903 independent edges, the raw coloring space contains

2903 2^{903}

colorings before symmetry reduction.

Neighborhood

A state's neighborhood is the collection of states reachable by one allowed action. Under single-edge flipping, there are at most 903 immediate neighbors before memory restrictions.

Action space

The action space is the collection of transformations available to the policy. Changing the action definition changes the geometry of the search problem even when the underlying set of colorings is unchanged.

Exploration

Exploration means trying actions or regions that are not currently known to be best, in order to discover new structures or escape local behavior.

Exploitation

Exploitation means using currently known information to choose actions expected to perform well immediately.

Local versus global optimum

A local optimum is best only with respect to a specified neighborhood. A global optimum is best among all possible states.

A single-edge local minimum is therefore not evidence that no better coloring exists.

Phase / search phase

A phase is an experimentally chosen regime using particular seed distributions, policies, models, or objectives. Our neural experiments used progressively lower-score archives as later training phases.

Plateau criterion

A plateau criterion is an empirical rule for deciding that continued use of a particular search/training method is no longer producing meaningful benchmark improvement.

18. Key Experimental Lessons Encoded as Terms

Greedy wall

The greedy wall is the experimentally observed regime where single-edge exact greedy search has driven the score low enough that almost no improving edge flips remain.

It is not a universal mathematical constant such as “score 300”; its location depends on state and search history.

Flexibility collapse

Flexibility collapse is the reduction of the F(b)F(b) curve during aggressive greedy score descent.

In our measured action landscapes, F(0)F(0) fell from roughly half of the action space for random states to well below one percent near the low-score frontier.

Constraint reorganization

Constraint reorganization means changing which edges/K5s carry blocker and violation responsibilities, potentially without immediately reducing Ramsey score.

Thermostat behavior

Our first fixed-floor flexibility policy displayed thermostat behavior:

  1. greedy descent consumed flexibility;
  2. the policy crossed below its F(5) floor;
  3. reorganization restored flexibility;
  4. greedy resumed;
  5. the process repeated.

This demonstrated control over flexibility but was not assumed to be the final policy.

Same-score structural difference

The matched-score experiment established that two colorings can have essentially identical Ramsey scores yet substantially different flexibility curves.

Therefore Ramsey score does not uniquely characterize the local search landscape.

Flexibility opportunity versus progress

Flexibility is opportunity, not progress summarizes the observation that having many inexpensive actions does not itself reduce Ramsey score. A policy must use that optionality effectively rather than immediately consume it.

21. Guiding Research Principle

The most important conceptual lesson behind many of these definitions is:

Do not compress structural information into a scalar until we understand what the scalar destroys.

Ramsey score is indispensable because score zero is the ultimate target, but it does not describe how constraints are arranged. The role profile (N1,…,N10)(N_1,\ldots,N_{10}), the flexibility curve F(b)F(b), directional completion deficits, repair landscapes, action counterfactuals, and Pareto frontiers are all attempts to retain structure that a single number discards.

The evolving search question is therefore not merely:

Which action reduces the most violations right now?

but:

Which action makes genuine progress while leaving the coloring in a state from which future progress remains possible?
